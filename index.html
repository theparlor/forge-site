Composition

One frame. Every platform. Nothing lost.

Forge is a composition engine. Give it a methodology, a persona, and a target platform — it renders a deployed skill without losing the source thinking or the attribution chain. The formula is irreducible: Methodology × Persona × Platform = Deployed Skill. Change any factor; everything downstream re-renders correctly.

The problem it solves

Your best thinking exists in one place. It should work everywhere.

A product operating model encoded as a Confluence page is dead on arrival in a Claude Code session. The same thinking expressed as a Copilot extension is useless in a workshop. You can't copy-paste methodology across surfaces without losing the reasoning — the constraints, the anti-patterns, the sequencing logic that makes it work. Forge solves this by treating the methodology as the master and every platform rendering as a projection. The source is authoritative; the renderings are always derivable from it.

The methodology is the source of truth. Every platform gets a rendering. The rendering is never the original.
The rendering formula

Three inputs. One deployed artifact.

×

Methodology

Platform-agnostic process definitions — the thinking, sequencing, output shape, and quality criteria. Pure IP. No platform-specific packaging or triggers. This is the master.

×

Persona

How the methodology gets voiced for a specific audience. Named practitioners, discipline archetypes, organizational roles, audience maturity levels — swappable without touching the methodology.

=

Deployed Skill

A rendered artifact for a specific platform: a Claude Code SKILL.md, a Copilot declarative agent, a raw system prompt, a workshop guide. Same thinking; right container.

What makes it different

The source constraint: methodology is never embedded in a rendering.

The rule the whole engine is built around

A rendering is not a copy.

Most skill-authoring approaches produce one-off artifacts: a Claude skill written directly for Claude, a Copilot extension written directly for Copilot. When the thinking changes, every artifact needs a manual update. Forge enforces a source separation: methodology lives in its own layer, platform rules live in their own layer, and the rendering engine composes them at build time. Swap the platform spec and the same methodology re-renders without drift. The two outputs of every composition are:

The methodology layer

Platform-agnostic, attribution-bearing, reusable across every surface. This is what you own.

The rendered skill

Platform-specific, correctly packaged, always derivable from the source. This is what you ship.

How Forge was forged.

Forge wasn't designed to be a tool. It was built because the alternative — re-encoding methodology by hand for every platform — compounds debt faster than any team can repay it. The operating model that governs Forge is the same one that produced it, and it composes into a larger system where Forge occupies the Composition position.
